# Legacy experiment scripts

This directory contains the original numbered scripts from the research workflow. They are retained for transparency and reproducibility of the development trajectory.

The maintained inference/deployment implementation is now under:

- `src/ccpredicting/`
- `app/streamlit_app.py`

Several legacy scripts require the original private clinical Excel file. The raw clinical dataset is not included in this repository. Use an approved local path through environment variables or configuration before running those scripts.
